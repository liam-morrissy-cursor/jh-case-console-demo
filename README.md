## Use

- GitHub Pages (recommended): enable Pages from `main` / root → open `https://liam-morrissy-cursor.github.io/jh-case-console-demo/`

## Demo path

1. Sign On (ANALYST01 / demo)
2. Retrieve `JIRA-001`
3. Bot posts a **case log** entry
4. Leave **Apply Parameter Change** and **Send Customer Notice** alone (human-only / disabled)
